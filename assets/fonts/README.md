# Manrope

The regular (400), medium (500), semibold (600), and bold (700) WOFF2 files are fixed-weight instances of the existing `manrope-latin.woff2` variable font. Fixed weights avoid inconsistent axis rendering in the Windows WebKit browser engine.

All font files are served locally. Manrope is licensed under the SIL Open Font License 1.1; see `Manrope-OFL.txt`. Upstream family: https://github.com/google/fonts/tree/main/ofl/manrope.
